6 data prompts to practise with

Copy a prompt, replace the [BRACKETS] with your details, run it in any AI tool, then check the result. Each prompt includes the habit that makes it reliable.

1Spreadsheet formula

In Google Sheets, column A has [DATA], column B has [DATA]. Write a formula for [GOAL]. Explain each part and give 3 test rows with the expected result.

Make it reliable: Test rows prove the formula works.

2Clean this list

Standardise this list: fix capitalisation, spelling variants and extra spaces. Return a table: original | cleaned | change made. Do not drop any rows.

[LIST]

Make it reliable: A change column makes cleaning auditable.

3Chart choice

I have data on [DESCRIPTION]. Which chart type best shows [QUESTION], and what would mislead? Give the axis labels and title.

Make it reliable: Start the y-axis at zero for bar charts.

4Insight check

Here is a summary table: [TABLE]. List 5 observations, and for each, say whether the data proves it, suggests it, or cannot tell.

Make it reliable: Separating proof from suggestion is the core skill.

5SQL helper

Table [NAME] has columns [COLUMNS]. Write a SQL query to [GOAL]. Explain it line by line and note any edge case (nulls, duplicates).

Make it reliable: Run it on a copy first.

6Survey design

Write a 7-question survey to learn [GOAL] from [AUDIENCE]. Use simple language, mix multiple-choice and one open question, and avoid leading wording.

Make it reliable: Pilot with 3 people before sending.
